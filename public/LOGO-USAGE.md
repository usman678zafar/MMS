# MMS logo assets

All PNG files use transparent backgrounds.

- `logo.svg` / `logo-color.png`: primary symbol-and-MMS logo for light backgrounds.
- `logo-white.svg` / `logo-white.png`: monochrome logo for dark backgrounds.
- `logo-black.svg` / `logo-black.png`: monochrome logo for print and single-color use.
- `logo-mark.svg` / `logo-mark-color.png`: primary square application mark.
- `logo-mark-white.svg` / `logo-mark-white.png`: standalone mark for dark backgrounds.
- `logo-mark-black.svg` / `logo-mark-black.png`: standalone mark for print and light backgrounds.
- `logo-full-name.svg` / `logo-full-name.png`: icon with the complete product name.
- `logo-full-name-white.svg` / `logo-full-name-white.png`: full-name logo for dark backgrounds.
- `logo-full-name-black.svg` / `logo-full-name-black.png`: full-name monochrome print logo.

Keep clear space around the logo and do not stretch, rotate, recolor, or add gradients.
